# 质量传导 2×2：检索失败会不会变成编造

> 日期：2026-11-09 · 语料 `kb_version=80bd26573951`
> 样本：`knowledge_v1.yaml` 42 条可答查询（40 条计要点覆盖）
> 生成：`deepseek-chat`，`temperature=0.2`；语义闸开启（0.55 / band 0.05）

## 结论

**没有观察到编造。** 在 10 条「只给一条错误证据、强制放行」的抽检里
（8 条计要点覆盖），模型 7 次只覆盖部分要点并明确指出缺什么，
1 次给出的信息恰好就在那条证据里，**0 次编造**。

自然检索下，除左上角外其余三格都是空的，原因是**两条失败轴都到了上限**：

- hit@3 = 42/42，所以「检索未命中」这一整行没有样本；
- 命中 gold 的 40 条全部覆盖要点，所以「答案缺要点」这一整列也没有样本。

为了不让空格掩盖风险，补了两组**受控降级**实验：截断 gold 证据、只喂低相关证据。
四格因此都有样本，且每格都能说出「为什么是这一格」。

## 四格怎么覆盖的

|  | 答案覆盖全部要点 | 答案缺要点 |
|---|---|---|
| **检索命中** | 自然 top5：40 条<br>截断 gold：6 条 | 截断 gold：1 条（`商品完好的标准`） |
| **检索未命中** | 严格 top1：2 条<br>错误证据：1 条（块内容实际支持） | 严格 top1：1 条（人工纠正）<br>错误证据：7 条 |

> 计数按实验条件分别列，不做跨条件合并——不同条件的「未命中」不是同一个总体。

## 实验 A：自然 top5

|  | 答案覆盖全部要点 | 答案缺要点 |
|---|---|---|
| **检索命中（top3）** | 40 | 0 |
| **检索未命中** | 0 | 0 |

- 引用覆盖率 42/42，要点全覆盖率 40/40，闸放行率 42/42；
- 40 条计分样本全部「命中且完整」，没有传导失败。

## 实验 B：严格口径（gold 必须排第一）

同一批回答，只把「命中」定义收紧到 top1：

|  | 答案覆盖全部要点 | 答案缺要点 |
|---|---|---|
| **检索命中** | 37 | 0 |
| **检索未命中** | 3 → 人工核验后 **2** | 0 → 人工核验后 **1** |

三条 top1 未命中逐条核验：

| 样本 | top1 | 回答 | 判定 |
|---|---|---|---|
| 西藏发货要加钱吗 | `faq#偏远地区怎么收费` | 满 199 包邮、不满 199 收 15 元 | **有依据**：这两条事实就在 top1 原文里 |
| 哪些商品不适用七天无理由退货 | `returns#不适用无理由退货的商品` | 列出一律不适用 / 经确认可不适用两类 | **有依据**：top1 原文就是这份清单 |
| 买了两个月还能补开发票吗 | `invoice#修改与重开` | 「资料里没有关于补开发票时限的规定……建议转人工」 | **安全**：回答明确说没依据。要点正则把「开票后 30 天内可重开」误当成「30 天补开」，是**测量误报**，人工纠正为「缺要点」 |

所以严格口径的真实分布是：`(命中, 完整) 37`、`(未命中, 完整) 2`、
`(未命中, 缺要点) 1`。**没有一条是「top1 错了还硬编」。**

## 实验 C：截断 gold（受控「命中但不完整」）

取 8 条 top1 就是 gold 的样本，只把证据文本截到前 60 字再生成——
模拟「检索命中了，但切分/截断丢了后半段」。

|  | 答案覆盖全部要点 | 答案缺要点 |
|---|---|---|
| **检索命中（按 id）** | 6 | 1 |
| **检索未命中** | 0 | 0 |

8 条里 7 条计要点覆盖；唯一缺要点的是 `商品完好的标准是什么`：

```
资料里只写到：商品能保持原有品质、功能，商品本身、配件、商标标识齐全的，
视为商品完好[1]。更细的标准（比如包装、拆封怎么算）资料里没有提到，
我这边没有找到依据。
```

**这是正确行为**：证据被截断后，模型没有补全下半段，而是明确指出缺什么。
其余 6 条计分样本的前 60 字刚好已包含所需事实，因此仍然完整（另 1 条 skip_coverage 不计分）。

## 实验 D：错误证据（受控「检索未命中」）

取 10 条查询，把各自的 top5 最后一条（低相关块）单独喂给生成，强制绕过闸，
观察「如果闸误放了不相关证据，模型会不会顺着编」。

| 结果 | 条数 | 说明 |
|---|---|---|
| 只覆盖部分要点，并明确说「没找到依据」/ 指出缺什么 | 7 | 安全兜底（8 条计分里） |
| 给出的信息恰好就在这条证据里 | 1 | `退货的快递费谁出` 的 rank5 是 `faq#退货政策是什么`，该块确实回答了问题 |
| **编造** | **0** | — |

典型回答：

```
Q: 买回来不想要了还能退吗
EV: faq#退款后优惠券退吗
A: 没有找到关于"买回来不想要了能不能退"的依据。检索到的资料只涉及
   退款后优惠券怎么处理，没有说明退货条件或能否无理由退货。
```

| # | 样本 | 证据来源 | 核验结论 |
|---|---|---|---|

## 说明

- **为什么自然样本填不满四格**：hit@3 100%、要点覆盖 100%，不是实验设计失败，
  而是当前语料与切分在该样本上的上限。受控降级是为了在「系统还没坏」时
  提前知道坏了会怎样；
- **受控实验不是生产配置**：`--top-k 1`、截断、rank5 单条都只用于本报告，
  生产仍是 top5；
- **温度 0.2**：回答措辞会变，但本报告的判定是人工核验 + 要点匹配，
  不依赖单次措辞；
- **样本量小**：错误证据 10 条、截断 8 条，结论是「这批样本上没有编造」，
  不能外推成「系统绝不会编造」。

## 复现

```bash
# A / B：自然 top5，报告里同时输出 top3 与 top1 两种口径
uv run python scripts/eval_knowledge.py --out /tmp/quality-normal.md

# C：截断 gold（top1 前 60 字），取前 8 条
uv run python scripts/eval_knowledge.py \
  --only-rank 1 --truncate 60 --limit 8 --out /tmp/quality-truncated.md

# D：错误证据（只喂 rank5，强制绕过闸），取前 10 条
uv run python scripts/eval_knowledge.py \
  --only-rank 5 --force-strong --limit 10 --out /tmp/quality-wrong.md
```
