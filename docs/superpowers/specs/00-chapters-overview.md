## 依赖

```
Ch01 ──► Ch02 ──► Ch03 ──► Ch04
  │                 │        │
  └──► Ch05 ────────┴────────┴──► Ch06 ──► Ch07 ──► Ch08
```

**可并行**：Ch02（写文档）与 Ch01 后半段（建表+seed）可同时进行。

## 每章的固定结构

```
## 目标（含验收标准）
## 技术栈（定死）
## 架构
## 目录结构
## 数据模型 / 核心逻辑
## 接口契约
## 测试与验证
## 本章不做
## 关键决策记录
```

**「本章不做」和「关键决策记录」是硬要求**——前者防止范围蔓延，后者是面试素材。
